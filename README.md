# Pocket Book — Monev Prasarana Strategis Sulsel 2026

Static site sebagai pocket book peserta kunjungan lapangan **Monev Prasarana Strategis Sulawesi Selatan**, 11 – 13 Mei 2026.

**Live**: https://raflianwarmra.github.io/monev-ps-sulsel-2026/

## Konten
- **Agenda & Lokasi** — rundown 3 hari + 6 titik kunjungan dengan link Google Maps & peta interaktif.
- **Profil Ditjen Prasarana Strategis** — tugas, fungsi, dan 3 program prioritas presiden (Sekolah Rakyat, PHTC Madrasah, SPPG).
- **Infrastruktur** — profil paket per kabupaten/kota (Makassar, Maros, Takalar).
- **Kontak PIC** — Rafli & Hazim (klik-WhatsApp).

## Stack
HTML/CSS/JS murni · Leaflet (peta) · Inter (font) · GitHub Pages.
